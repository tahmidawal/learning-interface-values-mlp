# Archive Directory

This directory contains the original files from the project that have been organized into version-specific directories (v1, v2, v3) in the root folder.

## Contents

- Original Python source files
- Test results and output directories
- Data samples and model files
- Example directories and test cases

This archive is maintained for reference purposes. For active development and usage, please use the organized version directories in the root folder:

- `v1/`: Basic Interface Prediction
- `v2/`: Subdomain Integration
- `v3/`: Low-K Numerical Solutions
